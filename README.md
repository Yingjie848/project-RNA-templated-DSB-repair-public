# RNA-templated DSB repair
This resource deposites the code used in RNA-templated DSB repair paper, including:
1) run CRISPResso to analyze CRISPR/Cas9 screen data. CRISPResso aligns reads to the target region using a global alignment algorithm after merging read pairs with FLASh.
2) identify whole intron deletions (WID) in PCAWG and IMPACT datasets.
